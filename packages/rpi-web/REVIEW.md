## 已修复的问题

| 优先级 | 问题 | 修复与验证 |
| --- | --- | --- |
| P1 | Git diff 接受目录及通配路径，可能绕过受限文件过滤；项目内符号链接也可指向受限文件 | 对实际目标再次检查限制；Git 使用字面路径，diff 仅接受单个文件；Linux 验证隐藏文件别名及目录链接 |
| P1 | 损坏的会话索引被当成空索引；写入失败仍返回保存成功 | 读取损坏时明确报错；新增、重命名、删除及归档写入失败均回滚；提示词提交前先保存必要元数据 |
| P1 | 多个页面同时重开同一会话可启动多个原生写进程 | 串行化重开与删除；隔离集成测试用 8 个并发请求确认仅一个原生子进程 |
| P2 | 旧会话的队列、分页及运行时设置请求可能污染新会话；归档和新建的迟到响应可能改变用户后续选择 | 请求结果校验当前会话与请求版本；切换时清理授权输入等状态；浏览器复现并回归验证 |
| P2 | 会话列表读取失败后自动新建会话；登录过期后不断重连 | 区分读取失败和空列表；401 返回登录页并清理当前访问状态；验证可重新打开原会话 |
| P2 | 原生进程不发送 ready 时启动请求可一直挂起；分叉校验失败可能继续登记会话 | ready 读取有时限及大小限制，失败自动终止子进程；分叉必须确认会话 ID 与导航成功 |
| P2 | 嵌套项目 Git 路径错误；文件名含方括号时被当成通配符；新仓库显示 HEAD | 状态路径转换为项目相对路径；字面路径精确匹配；正确读取尚无提交的分支名 |

## 第二轮：RPC 并发、事件恢复与登录边界

| 优先级 | 问题 | 修复与验证 |
| --- | --- | --- |
| P1 | 事件流仅在建立连接时校验登录，退出后已有连接仍可接收后续数据 | 发送每条事件前重新校验，空闲连接定期校验；真实 HTTP 集成确认旧 Cookie 和旧事件连接同时失效，退出响应清除 Cookie |
| P2 | 多个调用使用同一请求 ID 时覆盖等待者，响应可能串线或超时 | 原生 RPC 使用内部唯一 ID，返回时恢复调用方 ID；反序响应测试及真实原生进程并发检查通过 |
| P2 | 响应超时、取消后等待记录残留，排队本身不受超时控制 | 超时覆盖入队和响应等待，退出作用域自动清理；已过期的排队命令不会发送到原生进程 |
| P2 | 原生 stdin 写入失败只推送极大事件序号，等待请求仍挂起 | 写入失败沿统一关闭路径记录正常序号的错误与关闭事件、终止子进程并结束等待；Linux 故障子进程保持 stdout 开启仍能及时处理 |
| P2 | 快照无增量时未设置前端游标，重放与实时交叠可重复显示；恢复后已关闭弹窗与中断提示可能重现 | 服务端过滤交叠序号，前端使用快照游标；先恢复基础状态再顺序应用增量；浏览器回归通过 |
